# User Quick Start

## What this tool does

Research Reference Checker helps you review a reference list before submission, supervision, or internal review.

It can help you:
- spot missing details such as authors, year, journal, DOI, or URL
- notice when a journal or publisher matches a loaded warning list
- see whether a parsed journal is listed in DOAJ
- keep an institutional watchlist for manual review

## 2-minute workflow

1. Open the app.
2. Paste references, one per line.
3. Click **Review references**.
4. Read the **What to do next** column first.
5. Open **Inspect reference** for any item you want to understand in more detail.

## How to read the results

- `Check immediately`: review this reference first.
- `Check manually`: something may need human judgement.
- `Add missing details`: the reference is incomplete.
- `Looks OK`: nothing urgent was found in this run.

Important:
- `No registry match` does not mean a source is automatically trustworthy.
- `Not listed in DOAJ` does not automatically mean a journal is problematic.
- The tool supports review; it does not replace subject expertise or institutional policy.

## Good practice

- Keep one full reference on each line.
- Use the default settings first.
- Export the results if you want to share them with a colleague or supervisor.
