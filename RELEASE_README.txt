Research Reference Checker (Windows)
====================================

1) Unzip the whole folder and keep the `data` folder next to `ReferenceChecker.exe`
2) Double-click ReferenceChecker.exe
3) Paste references, one per line
4) Click "Review references"
5) Export CSV/Excel if needed

Notes
- No Python installation is required for this packaged build.
- On first launch, Windows SmartScreen may show a warning. Choose:
  "More info" -> "Run anyway" (if you trust this source).
- The app opens in your web browser on your own computer.
- The included `data` folder contains the bundled registry files and abbreviation database.
- Custom watchlist entries are saved to `data/custom_watchlist.csv` next to the EXE.
